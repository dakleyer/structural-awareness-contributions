## Release controls

- Binary files are preserved by SHA-256 so a future public release can be checked against the audited package.
- Editable Word files contain no active comments, tracked changes, hidden text or external relationships at the time of packaging.
- Acknowledgement, posting or discussion does not mean adoption, endorsement, acceptance or institutional validation.
- No licence has yet been selected. Publication should therefore include a deliberate licensing decision.
- Email correspondence and internal control records are not included in this public-ready library.
