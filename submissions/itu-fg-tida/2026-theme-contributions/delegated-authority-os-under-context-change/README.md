# TIDA — Delegated Authority OS under Context Change

## Public pre-freeze working package

- **Status:** Public working material for collaborative FG-TIDA discussion; not an adopted or endorsed FG-TIDA deliverable.
- **Version control:** Canonical filenames remain stable. Document revisions are recorded inside each file and in Git history.

## Canonical documents

1. [Case design and pre-freeze working structure](01_Case_Design_and_PreFreeze_Working_Structure.md) — purpose, ideal pre-freeze design conditions and freeze logic.
2. [Annex I — Minimal Operational Case](02_ANNEX_I_Minimal_Operational_Case.md) — public-facing explanation, concrete mobility case, technical completion and next-use paths.
3. [Annex II — Case Extensibility](03_ANNEX_II_Case_Extensibility.md) — upward, downward and horizontal extensibility, including the private-factory boundary test.
4. [Annex III — Challenges Exposed by the Case](04_ANNEX_III_Challenges_Exposed_by_the_Case.md) — current S1–S14 post-freeze solution-challenge framework.
5. [Annex IV — FG-TIDA ToR Mapping and Traceability](05_ANNEX_IV_FG-TIDA_ToR_Mapping_and_Traceability.md) — case and challenge traceability to the FG-TIDA Terms of Reference.
6. [Annex V — Adjacent Standards and Research Relevance](06_ANNEX_V_Adjacent_Standards_and_Research_Relevance.md) — controlled interfaces with adjacent groups, standards and research.

The package is intentionally modular. The main note explains what makes this candidate useful before freeze; Annex I contains the case itself; Annex II tests how far that case can extend without changing its core semantics; Annex III keeps the solution challenges separate from the case facts; Annex IV tests mandate alignment; and Annex V identifies controlled external interfaces.

## Claim boundary

This package is public working material. It does not claim FG-TIDA or ITU adoption, endorsement, validation, agenda inclusion or incorporation into an ITU-T deliverable.
