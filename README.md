# Structural Awareness Programme

> **Programme repository router.** Canonical public entry starts at [Iván Abril Palma](https://github.com/dakleyer/dakleyer). This repository routes into the principal Structural Awareness corpora, applied-research work and public contribution records. It is not itself the detailed index for those corpora.

Structural Awareness studies how technical and institutional systems act through incomplete representations of their own structure, dependencies and operating conditions, how those representations become insufficient as context changes, and how AI-enabled systems can respond with bounded evidence, authority and control.

The programme is developed through **Tegrity.AI, part of The Integral Management Society**. Individual workstreams retain separate ownership, evidence, validation and institutional status; links between them are architectural relationships, not transfers of validation.
