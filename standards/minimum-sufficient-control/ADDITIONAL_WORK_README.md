## ¿Está duplicado o tiene trabajo propio?

El contexto histórico y la arquitectura genérica cumplen papeles distintos. La propia auditoría fechada de conservación identifica el antiguo texto del README como fuente del contexto; eso explica su repetición histórica sin convertirlo en una segunda especificación vigente.

Word y PDF de una nota de dominio son formatos/artefactos de custodia relacionados, no dos validaciones. Su contenido binario no se ha comparado en esta organización; se enlazan desde sus manifests y se conservan. Los Markdown leídos declaran propósito, fuente y límites; la calidad científica del caso o del núcleo no se decide por ese formato.
