# Ecosystem Awareness — current baseline corpus

This folder is the **primary public corpus of Ecosystem Awareness (EA)**. Read the documents below in order. The current foundation and benchmark are public working successors; the controlled v0.4 source files remain preserved and are not silently rewritten. [Corpus publication manifest](../CANONICAL_CORPUS_MANIFEST.md) states what is public, what is frozen and what still lacks revision-anchored SHA verification.
