## Question, subject and declared decision

Can a case-dependent escalation preserve its report, obtain a qualified timely response, apply only a current scoped decision, confirm the digital effect and continue the useful mission? What information, authority, capacity, continuity and cost conditions limit that path?

The subject has three distinct objects: the existing R01 mathematical mechanism profile; the proposed identity/state/delegation consumption studies; and the concrete local model `HEW-DDS-SQLITE-MODEL-0.2`. Only the last is executed here. STAMP/STPA informs the constraints; SPIFFE/SPIRE and RATS remain documentary/profile references. Fencing, delegation checks, local command identity, reservation, event storage and outbox are independently authored model controls, not vendor implementations.

## Architecture and information boundary

The model implements:

1. A filed operation bound to tenant, principal, deputy, resource and owner.
2. A local atomic filing/outbox transaction. Two affected recipients receive a minimal scoped notification; copies preserve one evidence origin. Filing requires no majority. Only the affected receipts required by this selected profile gate its effect.
3. One-tick owner acknowledgement and three-tick qualified review, using the same physical-person reservation table. Current calendar data is stipulated; unknown capacity blocks reliance without deleting the case.
4. Applicable basis/version, supplied identity/state assertions, independently provisioned current authority, declared continuity and semantic binding checked at effect time.
5. A resource floor and digital effect committed in one local SQLite transaction. Generation is not delegated authority. The floor survives normal close/reopen; hardware/distributed durability is outside the test.
6. Per-command identity, queryable local effects, lost-reply UNKNOWN and reconciliation, followed by recorded qualified reentry/delivery.
7. Append-only event API triggers, hash-chain auditing, minimum notification payload and scoped case reads. Database administrators/OS access are not isolated; organizational non-retaliation is not measured.

The controller receives only the declared public fields; expected outcomes and private-world truth go only to the post-run adjudicator. This is API projection and source-code separation for the declared controller, not a blinded human study or a sandbox against arbitrary malicious Python. Scenario identifiers/narratives are public test metadata; no adversarial metadata-isolation result is claimed.

The oracle reads actual SQLite effects/events, reconstructs acknowledgement/review/application/delivery deadlines and work, and checks the declared private world. It ignores controller success/confirmation/work assertions when determining the actual outcome. Calendar reference uses exhaustive integer starts rather than the controller's first-slot construction. Both methods are from the same author; independent external review remains pending.

## Configuration, timing and full declared work

The reference model has arrival2, acknowledgement deadline3, decision6, application7 and delivery8. A free eligible person acknowledges over[2,3), reviews over[3,6), applies at7 and delivers at8. Adding one sequential gate tick makes this fixed application window fail. Checks have zero reference tick latency and a charged work tariff; this is a model assumption, not a measured zero-latency service.

For a complete nominal case, the declared work is:

```
1 filing + 1 source preparation + 2×2 recipient processing
+ 1 owner acknowledgement + 3 review + 5 checking bundle
+ 1 digital application + 1 confirmation + 1 delivery = 18 work units.
```

The common case ceiling is20 units. Restart-pair instances use24 units, selected before A1 execution to separate insufficient-basis failure from added-message budget exhaustion. A separate budget16 control rejects the otherwise useful effect. No budget resets across a case's recorded restarts. Costs are reconstructed from milestones and the fixed tariff, not accepted from a controller summary.

These are abstract declared work units, not actual salaries, token prices, SQL operation costs or the original R01 h units. Actual source acquisition, roster preparation/reserve, integration, infrastructure/idle capacity, cryptographic lifecycle, storage administration, recovery and network latencies require a deployment ledger. No source becomes cheap because its message is short.

Prospective deployment cost is `C_setup + C_integration + C_sources + C_reserved_capacity + Σ C_case + C_maintenance + C_recovery`, with shared work attributed once. The DDS service fee is separate. The cost of material evidence and any admissible alternative must be included before a technology–problem suitability conclusion is transferred.

## Business Value–Risk–Cost correspondence

Technical C–R–E and its original acceptance semantics remain unchanged. At the deployment layer, useful business/process value must be declared for the particular objective. This research example uses sufficient legitimate delivery in useful time, critical-duty continuity, timely accountable response and preserved reporting as separate indicators. They are not monetized or merged into a universal utility score.

Residual risk includes source falsity/incomplete coverage, real review error/capacity, delayed or unavailable intervention, unsupported continuity, current-authority propagation, unguarded effect paths, malicious/admin storage access and unresolved effect knowledge. A hard authorization/continuity violation cannot be compensated by throughput. The false-appraisal diagnostic explicitly limits any blanket source-sufficiency claim.

Strong fit in the admitted model: a known eligible slot, truthful applicable basis, scoped current grant, reachable local digital effect and sufficient time/work permit the complete path. Conditional fit: an admitted backup/handover or corrected fresh basis can recover a case if it is genuinely available and charged. Not established: native/human deployment performance, economics, malicious-code isolation, distributed source truth and physical fleet-effect coverage.
