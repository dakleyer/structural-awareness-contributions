## Executive finding and scope

A correctly framed selected request can reach an admitted local effect when its actual tool contract and current resource mandate hold. Self-reported client identity and tool hints do not establish permission or no-effect guarantees. One legitimate local tool path and its failure boundaries are tested; native MCP interoperability/conformance remains unestablished.

The [extension](./EXTENSION.md) supplies Stage1 correspondence/transfer limits and Stage2 mechanism sources/burdens. Scope is the written scalar request handler and actual SQLite resource, not the entire protocol or a production host.

## Preregistration, trace and oracle

[Card](./RUN_CARD.json), [Freeze](./FREEZE.json) and [study.py](./study.py) are frozen before execution. The script checks runtime/hash pins and creates a fresh output directory. Requests are actually serialized and parsed; local SQL operations/effects and response/error data are recorded. The prototype's error records are not full native JSON-RPC wire responses.

A separate post-effect SQLite connection inspects actual operation/tenant/tier rows. The driver retains the scenario's permitted contract; the handler does not receive the expected result. Current resource checks are real local database reads inside the selected transaction. This does not prove distributed atomicity, all tool enforcement paths or blind/independent evaluator separation.

## Cost, Risk, Effectiveness and Business Value

**Cost:** actual serialized request bytes and operational SQL statements, including current grant/replay checks. Schema/table setup, producer work, token/identity sources, hosts/transport/network, discovery, catalog governance, maintenance, downstream work and real latency/tariffs are unscored. There is no calibrated deployment C ceiling.

**Risk:** declared wrong/unauthorized/duplicate local effect. Zero P in this finite chosen battery is not zero deployment risk. A compromised trusted registry/authority source, unsupported arguments or an external effect path can invalidate transfer.

**Effectiveness:** one sufficient admitted local write versus Ø. Tool reasoning, real API performance, user/task usefulness across products, M-reference closure and population E are unmeasured. Rejecting an unsupported request preserves control but does not deliver the mission.

**Business Value:** conditional predictable scoped tool admission and replay safety, with explicit producer/task limits. It does not establish enterprise authorization, physical outcome truth, staff availability or financial ROI. Commercial engagement fees remain separate.
