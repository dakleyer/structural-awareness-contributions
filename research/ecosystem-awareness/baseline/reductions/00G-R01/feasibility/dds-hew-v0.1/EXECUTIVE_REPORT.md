# Human escalation and whispering — DDS executive research summary

6 October2026 · research edition0.1 · scoped analytical/model evidence.

**Finding:** an escalation becomes operationally useful only when the case is preserved, sufficient review is available, the decision authorizes the actual intervention, the resource applies it under current conditions and the effect is confirmed. The first integrated model makes these distinctions inspectable. It does not establish an incremental advantage over an existing competent solution or measured human effectiveness.

The study selects20 paired scenario descriptions across10 local problem types. Two profiles reconstruct the published R01 mathematics;18 scenario instances execute a deterministic SQLite control model. A further source-truth counterexample is retained.48 functional assertions and42 calendar-reference comparisons pass, while actual episode outcomes remain separate:11 useful sufficient deliveries,9 unresolved/not-delivered operations and1 violation under deliberately false source appraisal. No success percentage is inferred from this designed set.

The model tests shared reviewer reservations, scoped minimal whispering, owner response and preserved filing, current stored authority versus stale caller descriptions, purpose applicability, resource generations, command identity, local outbox recovery and effect knowledge. A receipt, review, valid identity or approval is not substituted for confirmed mission delivery.

The strongest practical boundary is upstream truth: the controller can consume a false assertion correctly and still produce a wrong result. Other limits include real workload/reviewer error, unavailable legitimate pause/handover, added check latency, incomplete resource coverage and protection against database/OS administrators. Native SPIRE/RATS/STS and real humans were not executed. No production assurance, standards adoption or provider ranking is claimed.

The original q90 % describes a source's useful certificate coverage under its stated law; p95 % is an efficacy target. They are not measured human resolution rates. The new SQLite model has separate synthetic time/work units and does not recalibrate those mathematical parameters.

For a deployment owner, the next useful decision is whether existing controls already provide the same case/authority/capacity/effect composition, which dependencies remain unqualified and whether the extra control work still fits the useful window. For a technology provider, the record identifies the documented native capabilities to credit and the source/realization facts needed before stronger claims.

The business interpretation stays bounded: useful legitimate completion, service continuity, accountable response and reporting protection; residual risk and lifecycle cost reported alongside them. Cost includes source production, review/reserve, communications, validation, integration and recovery. No ROI, euros or universal product suitability are inferred.
