## Why this fixture follows A6a

The first P6 run on canonical 00G F/G produced a TRUE SUBSTITUTE: authority
alone separated the false and genuine frame branches. That means 00G's original
pair is confounded for P6 necessity.

This companion fixture isolates the composition question using 00F's shared
corridor pressure. Authority, freshness and local determination are held equal.
The only material branch difference is whether the independently valid local
postures are **compatible over the same resource-time segment**.

## Branches

- **Hazard:** ambulance, fire and bus postures are all locally authorized,
  fresh and determined, but opposed uses overlap on the same corridor/time.
- **Compatible positive control:** the same local actors and local validity
  remain, but their resource-time uses do not conflict.

## Result

**11/11** symbolic tests pass.

- local-only execution, more local evidence and "no UNKNOWN" all execute the
  hazard because no local component is wrong;
- a blanket mutex/static-priority repair suppresses the hazard but also fails
  the compatible positive branch;
- a strong non-EA compatibility arbiter passes both branches, but it does so by
  explicitly computing cross-participant resource-time compatibility.

Under 00K this is **SEMANTIC RECONSTRUCTION of P6**, not evidence that EA/EP
owns the implementation.

No TRUE SUBSTITUTE is found in the tested repair surface of this isolated
fixture.
