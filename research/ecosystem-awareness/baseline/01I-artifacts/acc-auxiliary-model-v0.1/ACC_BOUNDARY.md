# Alcance del artefacto dentro de ACC

Este conjunto es un modelo de trabajo de sistemas y sociedad, deliberadamente bounded: suficientemente amplio para conservar y estudiar el desarrollo de Conscientia, limitado respecto a lo que define sobre ACC.

## Relación de alojamiento

Su propietario de lectura es la línea de ciudadanía agéntica; su función es aportar material de investigación para uso posterior. El README permite encontrarlo, entenderlo y recorrer sus casos. El enlace no promueve sus modelos a condiciones normativas del contrato.

El modelo incluye economía, recursos, participantes, capacidades, fines, bienestar, información, transición y negociación. Puede representar actores humanos, colectivos, técnicos o mixtos y recursos sin agencia, según el estudio. No reduce su alcance al software.

## Decisiones que quedan fuera

- Definir todo ACC o sustituir su anexo 01I.
- Generalizar ahora el alcance normativo del ACC canónico.
- Establecer cómo se incorpora ACC dentro de un agente.
- Diseñar sus módulos internos, emisión de contratos, integración de identidad o protocolo universal.
- Transferir al modelo la propiedad de ABCD, MSCA, autoridad, señalización o ejecución.
- Elegir una finalidad universal o una agregación obligatoria de bienestar.
- Afirmar que el sistema o sociedad simulada están validados por un ejemplo.
- Cambiar casos UC21, contratos DDS, resultados históricos o reglas de sus campañas.

La propuesta anterior de convertir este trabajo en una generalización de todo ACC queda fuera de este encargo. Los documentos previos se conservan como historia; esta delimitación más reciente gobierna el paquete.

## Posible utilización posterior

Un desarrollo futuro podrá seleccionar hipótesis, medidas, casos o resultados de este artefacto para informar un perfil ACC, un análisis institucional o una prueba. Tendrá que declarar qué selecciona, qué transforma, quién lo recibe, compatibilidad y evidencia. Esa selección no está resuelta por la mera incorporación al repositorio.

Las propuestas micro/meso/macro, ciclos y objetos de ejecución de las notas se conservan como diseños de investigación. No se presentan como el método ya elegido para integrar ACC en cada agente.

## Propietarios que permanecen

El [ACC](../../01I_AGENTIC_CITIZENSHIP_CONTRACT_HUMAN_GOVERNED_PARTICIPATION_PROFILE_v0.1.md) conserva participación/gobierno. Sus linajes, roles, autoridad y operación siguen sus fuentes. EA conserva cualificación epistémica; MSCA, control suficiente; DDS, el método de contraste. Los ejecutores conservan sus facultades. Este paquete articula preguntas que pueden relacionarlos sin reemplazarlos.
