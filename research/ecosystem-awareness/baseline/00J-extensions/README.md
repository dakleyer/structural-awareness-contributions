## Extension rule

An extension is not whole-system equivalence, a reduction or merely a horizontal move. It may preserve an **isomorphic subkernel** while adding states, actors, rights, use conditions, time regimes and dependencies that are not isomorphic. Transfer only the source result's *proved predicate* under preserved typing, comparator, parameter point, cost, horizon and observation boundary. Check new mechanism and coupling deltas independently. See the [R01 functional-kernel precedent](../reductions/00G-R01/extensions/family/KERNEL_AND_PROOF.md), the [R01 methodological foundations](../reductions/00G-R01/extensions/METHODOLOGICAL_FOUNDATIONS.md), [A25](../00K_A25_FAILURE_CASE_STUDY_EXTENSIBILITY_AND_CONFORMANCE_TRANSFER_v0.1.md) and [A26](../00K_A26_FAILURE_TO_SUCCESS_MODEL_CASE_AND_EXTENSIBILITY_v0.1.md).
