## Extension rule

An extension is not whole-system equivalence, a reduction or merely a horizontal move. It may preserve an **isomorphic subkernel** while adding states, actors, rights, use conditions, time regimes and dependencies that are not isomorphic. Transfer only the source result's *proved predicate* under preserved typing, comparator, parameter point, cost, horizon and observation boundary. Check new mechanism and coupling deltas independently.
