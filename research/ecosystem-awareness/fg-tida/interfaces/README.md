## Rule

The order is:

**general EA interface → ideal FG-TIDA mapping → current FG-TIDA mapping**

Theme numbers and Theme-specific semantics are confined to this application layer. The general EA interface remains expressed in capability/producer/consumer terms rather than FG-TIDA issue numbers.
