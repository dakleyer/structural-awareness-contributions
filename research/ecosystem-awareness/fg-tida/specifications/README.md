# FG-TIDA specification preparation

This folder prepares the **document layer** that could follow an accepted Charter / Working Group structure.

- [EA / FG-TIDA Specification Preparation Map v0.2 Draft](./EA_FG_TIDA_SPECIFICATION_PREPARATION_v0.2_DRAFT.md)

The document maps canonical EA sources into candidate specification sections, separates normative from informative/test-only material, records external-owner dependencies, and defines conformance/publication gates.

No file in this folder is an official FG-TIDA specification. An official specification would live in an FG-TIDA `wg<N>-...` repository after the appropriate organizational decision.
