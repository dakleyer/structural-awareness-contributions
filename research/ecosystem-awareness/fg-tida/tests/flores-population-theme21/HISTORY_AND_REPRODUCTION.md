### How this successor differs

- Earlier speculative Frame-Watch/B→C/Q-bind is **withdrawn** from active test claims.
- v0.4/0.5 casebooks and scores are **historical calibration**; they have partial/subjective oracles and no accepted blind EA results.
- v0.2 direct P0–P3 was the first narrow attempt; this campaign adds one canonical GitHub owner, explicit source custody, process-relative role mapping, independent-truth separation, strong-peer gates, known-defect record and a corrected local checker.
- Archive digests identify original bytes but do not prove hostile tamper-resistance absent external signed pin; immutable refs belong to git objects. The SHA values here are original-file checksums from the local working copy.
- The research-dossier confidentiality boundary means **private auditor-only casebooks are not copied into this public candidate folder**. Their exact byte custody needs a private archive/authorized vault if long-term remote reproducibility is required. This is a **remaining archival custody action**, not silently completed by the GitHub registration.

At repo root:

1. Run: python3 research/ecosystem-awareness/fg-tida/tests/flores-population-theme21/code/test_qualifier.py
2. Inspect: python3 research/ecosystem-awareness/fg-tida/tests/flores-population-theme21/code/qualifier.py research/ecosystem-awareness/fg-tida/tests/flores-population-theme21/code/mock_receipts.json --snapshot P2
3. Inspect mock source statuses, then review G00–G12 in ACCEPTANCE_AND_B2 before describing any outcome.

This reference checker implements explicit, preregistered proof dependencies over author-written facts and mocked event receipts; it does **not** run expected.py (which is owned upstream), infer truth, auto-extract source prose, authenticate sealed.json or implement an EA control plane. Its 21 checks are authored consistency assertions, not empirical success. The code is public for critique and as a strong B2-like baseline; an EA candidate would need a separate specified, blinded and fairly metered realization.
