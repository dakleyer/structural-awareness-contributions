## 4. Current architecture supported at contributor level

The public discussion supports the following contributor-level synthesis:

1. local/domain components produce bounded determinations and evidence;
2. outputs should preserve scope, attribution and unresolved state rather than silently collapse uncertainty;
3. a system-level Ecosystem Awareness function can compose what is established, unresolved, capacity-constrained and dependency-relevant;
4. independently governed participants require explicit interfaces rather than a required global orchestrator;
5. ecosystem signalling is a separate interoperable lifecycle for acquiring/correlating external information and supporting containment; and
6. a remaining architectural question is whether residual indeterminacy under the current observation/control architecture remains tolerable for the Objective Envelope or whether the frame must change.

This synthesis remains contributor-level / pre-standardization work.
