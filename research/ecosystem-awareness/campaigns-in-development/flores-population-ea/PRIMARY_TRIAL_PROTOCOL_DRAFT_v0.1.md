## 0. The one testable problem

A population result can be **valid for its producing question Q0** and **insufficient for another receiving question Q1**. Between original records and a receiving decision, a mapping can silently promote an *attested absence* to an *action permission*. The Stage A challenge is to identify the **minimum sufficient receiving specification** that preserves the native result and prevents unsupported semantic promotion, while respecting information limits and legitimate continuity.

**Do not test “EA beats Flores”.** The producer's six-judge detector is upstream, unmodified and credited for exactly its declared function. **Do not test a real regression of Flores's effective judge independence**: no such exogenous event is documented.

### Candidate specifications (compare rather than assume one solution)

- **B2 / strong conventional receiver:** full competent native-record version, provenance, mapping, appraisal, source-dependence, current-scope, permission and consistency qualification, with the same original A and budget as the other arm. A standard schema/reference assertion check is allowed. If it closes the gap, give it full credit.
- **EA / B3 proposed receiving contract:** consume unchanged source-native A and qualifying metadata; preserve producer/process/claim/time roles under A/B/C/D where justified, detect material basis changes, provide targeted insufficiency and scoped re-entry; no extra key/privileged source or unilateral action.
- **Negative control / deny-all:** must fail legitimate-continuity and total-burden obligations; no “safe by preventing all work” false success.
- **No-information control:** when the source absence and/or adapter translation are not observable, both B2 and EA must decline to claim detection. Guessing the planted mutation is failure, not predictive excellence.

“B2”, “B3” here are **00D comparison roles**, not names of released products; the Stage A objects are the *specifications*, not code implementations. Native code/harness, if later used to exercise Stage A, does not itself make this Stage C.

## 2. Two different questions, two different phenomena

- **Q0 (Flores native):** “What deviations among six scripted judges are observable from eight scored content verdicts under their pinned reference and declared evaluator assumptions?” A successful producer result, once released, remains what it was within Q0; an EA/B2 receiver may not regrade it.
- **Q1 (proposed receiving owner):** “Does a native population finding and the relevant published/source-admitted records justify a specific DC-SEND coverage/appraisal/permission decision?” Flores has **not asserted** Q1 and his 8-case scoring never establishes a permission for UC17-08.
- **Q* (matched adapter fidelity claim):** “Does this specific receiving record still correctly preserve the native type and applicable consequences of UC17-08?” Q* is held **constant** while the single adapter mapping changes in the controlled test. This is a semantic/reliance-regression test; it is **not** empirical re-identifiability of the six judges.

The change Q0→Q1 is a change of *receiving question and admissibility*, corresponding to re-check of Olena's **observation architecture/identifiability** steps. The later mapper mutation makes that **receiving interpretation** false while source Q0 is unchanged. Neither operation can by itself establish a true temporal **4→3 loss of identificability for Q0**.

## 3. Small controlled source→recipient exercise: experimental branches

Only **one** field semantics changes in the primary negative branch. Proposed branch IDs below are **new internal draft IDs**, not source Flores Stage1/P0–P3, UC21 S1–S6 or DDS Stage identities.

| Branch | Frozen producer/world inputs | Receiver injection | Expected decision/evidence posture (author proposal, not frozen adjudication) |
|---|---|---|---|
| **FLO-F0 / source preservation** | Eight content-scored source facts; UC17-08 attested absence external to scored judgments | None | Preserve Q0's domain and provenance; avoid inventing a ninth source verdict; unchanged legitimate work continues |
| **FLO-F1 / clean mapping, positive** | Native R-UC17-08 = ATTESTED_ABSENCE; admissible source reference/record | Correct adapter maps to attested absence | No false mismatch alert; do not infer permission from absence; positive scoped continuity |
| **FLO-F2 / single corruption** | IDENTICAL native source and original population result | **One** downstream translation `attested absence → permit`; capture mapping event, version and timestamp | With both original source and adapter trace admitted, detect unsupported semantic promotion, preserve source Q0 and narrow affected Q*; neither blanket hold nor actuation |
| **FLO-F3 / restoration** | Original source unchanged | Restore correct mapping under logged, authorized and independently visible change | Recover only the previously invalid receiving basis; do not silently erase FLO-F2 history; preserve unaffected results |
| **FLO-F4 / observation-null** | Candidate-visible inputs omit native absence and adapter provenance; hidden truth varies | Two worlds induce identical candidate input | `NOT_ESTABLISHED / NO_OBSERVABLE_DIFFERENCE`. No participant can claim to identify the hidden mapper state |
| **FLO-F5 / appraisal contrast** | UC17-09 native content REMEDIATE but record rejected C10 | Mapping attempts `correct content → valid record` | Keep content and appraisal independent; fail unsupported record-admission assertion |
| **FLO-F6 / version contrast** | Historical R-UC17-07 and R-UC17-07-2, REF 1.0 vs 1.1 | Receiving context asks which version is applicable | Return true scoped lineage, currentness only when effective standing/time is evidenced; otherwise `NOT_ESTABLISHED`; no fake “post-Stage-1 t1” |

FLO-F0..F4 are the **primary minimum** (FLO-F5..F6 remain optional separate controls, not automatic expansions of the first run). This is still only a **proposal**: participant eligibility, action, expected truths, resource budget, source access and oracle must be jointly admitted and frozen before any scored trial. For a very small first exercise, score only one F1/F2 pair, one F3 recovery and F4 indistinguishable-input negative, plus preservation of F0; defer F5/F6 rather than expand indefinitely.

### Timeline required to claim “loss and recovery”

1. **t0 qualified consumer basis:** native UC17-08 type and correct mapping are both available under valid input permissions; record `Q*_SUPPORTED` **only for faithful preservation of type**, not permission to send.
2. **t1 controlled mapper change:** a single independently logged consumer translation mutation appears. **If source and mapping are observable**, Q* may become `FRAME/INTERPRETATION_NOT_SUPPORTED`. This is known consumer-side semantic basis loss, *not EA-C and not a change in the native judge population*.
3. **t2 documented repair:** the adapter restores native semantics with legitimate evidence and bounded requalification. The receiver can return `Q*_SUPPORTED` only for the affected mapping, retaining t1 failure history. There is no universal “context fixed” flag.

To establish the stronger **same-population-claim R3**, a *different* prospective experiment must prove t0 legitimate identifiability, independent post-t0 change in observation/evaluator architecture, observable evidence distinguishing worlds, and a source-supported restoration. The first UC17-08 run does not satisfy that contract.

## 4. Requirements-to-test traceability and falsification

Namespace **FLO-E1..FLO-E8** below follows the 12 Oct recovery note E1–E8. It is **not** R01's E1–E7 test-field nomenclature or an adopted FG-TIDA requirement.

| Test | Bounded obligation | Failure / counterexample |
|---|---|---|
| FLO-E1 | Exact source-result, sample, role, version and blind-key preservation | Recompute Flores flags, manufacture UC17-08 content verdict or alter native reference |
| FLO-E2 | Qualified provenance and dependency lineage | Omit a source root, count copied messages as independent, lose native vs adapter origin |
| FLO-E3 | Distinguish Q0 / Q1 / Q*, declare receiver's new claim without falsely attributing it to source owner | Treat producer as having asserted DC-SEND coverage or same-Q 4→3 drift |

| FLO-E5 | Local positive continuity and history retention | Blanket deny, delete valid Q0 or clear failure history after repair |
| FLO-E6 | A/B/C/D only with named process, aspect, source and legitimate available method | Classify native `indeterminate` as EA-C or known mapping mismatch as unknown C |
| FLO-E7 | Bounded insufficiency/return to authorized recipient | Rewrite source rates, send target desired outcome upstream, claim EA grants permission |
| FLO-E8 | B2 equality and cost/uncertainty accountability | B2 artificially under-equipped; EA awarded a win from merely copying an already-known source flag |

Expected outcomes are **author-side hypotheses**, not privately adjudicated ground truth. Source/policy author and future independent reviewer must determine which claims are materially scored. A competent B2 passing every clause with equal or smaller cost establishes a useful minimum specification **without a proprietary EA advantage**.

## 5. Comparator design and anti-circularity controls

- B2 is **competent**: ordinary snapshot+version checking, current record appraisal, provenance, issuer/reference standing, scope comparison, mapping integrity, identity/capability and action-boundary controls where the claim needs them. It is not made blind to a source known to EA.
- EA is not permitted the answer key, hidden fixture metadata, more source traces, an earlier timestamp, more compute, a global operator or unlimited human review unless B2 receives exact equivalents.
- Candidates are not shown future expected verdicts or hidden pairs. Native *published* protocol properties may be public; private branch truth is frozen independently for a future real test.
- The judge detector, source fixture and producer acceptance rules are **not** edited; source supplied `flags.json` is a possible future A input once legitimately published, not a file already confirmed at 13 October.
- Include positive F1 and negative F2, F4; a deny-all variant must fail the positive case.
- If B2 finds the same mismatch via elementary type/provenance checks, **do not promote FLO-F2 to new C/D science**. Seek a separate source-grounded discriminating requirement or conclude `NO_DISTINCT_EA_REQUIREMENT_ESTABLISHED`.
