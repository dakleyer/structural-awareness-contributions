- Earlier speculative Frame-Watch/B→C/Q-bind is **withdrawn** from active test claims.

- Archive digests identify original bytes but do not prove hostile tamper-resistance absent external signed pin; immutable refs belong to git objects. The SHA values here are original-file checksums from the local working copy.

Their exact byte custody needs a private archive/authorized vault if long-term remote reproducibility is required. This is a **remaining archival custody action**, not silently completed by the GitHub registration.

These exercise **author-written local mock consistency checks**, NOT Flores's native generator/detector or a blinded EA-vs-B2 comparison. The 21 assertions comprise 17 direct checks, three association removals and that one trivial equality. Their success cannot be cited as independent causal falsifiers or EA performance. The old code remains available unchanged with this explicit limitation.
