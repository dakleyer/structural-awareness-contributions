## C. Two later audit arguments: ledger and self-uncertainty

[The separate residual-ledger analysis](./RESIDUAL_LEDGER.md) retains the nine original claims and evidence statuses. The auditor's residual ledger tabulates Flores §9 established/declared/unknown and §13 excluded surfaces, recomputes deltas after *hypothetical* controls; it is a competent B2-style baseline. A static dictionary of named claims and mode labels does not autonomously classify an unenumerated residual. Sample probe power demonstration with 96/12 cases is hypothetical, not a result. We retain the useful **coverage ledger concept** but decline to present its own lookup logic as uniquely EA.

The proposed second-order uncertainty claim is narrower than “all unknown changes trigger EA”: if a receiving profile is no longer justified, report **NOT_ESTABLISHED for the affected proof**, with reason and scope. B→UNKNOWN is admissible under 00M §6.1; neither C nor D nor world-change follows automatically. If the reconfiguration itself is invisible and observed metadata are identical across worlds, EA cannot infer the hidden difference. A B2 catch-all UNKNOWN with scoped dependencies is a full competitor; a detector-table straw man is invalid.

## D. v0.2 runnable prototype: known defect and corrected successor

Historical v0.2 had **15/15 authored self-checks and 4/4 metamorphic local edge removals**. Its qualifier is a generic recursive dependency checker, not source prose extraction, native Flores execution or EA-specific adaptation.

**Additional semantic defect identified 13 October:** historical qualifier marks Q_OBJECTIVELY_CORRECT REFUTED when a seal link was explicitly REFUTED, because the truth claim wrongly depended on the key-relative comparison. A failed seal invalidates comparison but does **not** refute independent truth of Cyril's key. New illustrative v0.3 code models Q_KEY_OBJECTIVELY_TRUE using only independent truth evidence, and expects NOT_ESTABLISHED even if seal is refuted. Historical bytes retained by SHA; not rewritten. Another limitation: mocked “attested” receipt booleans stand in for unpublished native artefacts. All current tests label them synthetic.

The v0.3 reference checker is itself **a strong conventional dependency-graph baseline**, not full EA; passing its internal tests is NOT an EA specification admission, blind-study success or scientific differential. Claims about automatically deriving the graph, authoring an EHD profile or adapting to genuinely unforeseen sources remain open. A fully defended B2 may tie this exact model.
