## 2. Mathematical results which must not be collapsed

These quantities **are not interchangeable**:

| Symbol | What it actually measures, under specified scope |
| --- | --- |
| \(H(R\mid O)\) | Shannon uncertainty about **receiver target R**, given O, under a declared joint law. |
| \(I(R;M\mid O)\) | New *conditional target information* supplied by a legitimate random-variable M beyond O. May be zero for an always-true open-world theorem. |
| \(\log_2|F_o|\) | Maximum conditional entropy possible on a **known finite fiber** (not actual H absent uniformity). |
| \(\log_2(N/n)\) | Finite **coverage ratio** for a certified N and nonempty observed subset size n; not bits of all unseen A′. |
| \(D_{\rm KL}(P(\cdot\mid C)\parallel P)\) | **Conditioning surprisal** under P(C)>0, equals \(-\log_2P(C)\); reverse direction differs. |
| \(K_U(x)\) | Shortest valid description in a specified universal machine; generally **not computable**. |
| \(C-K_U(x)\) | Source's formal capacity-description gap for a specified C; not work/heat and not automatically r-sufficiency. |
| \(\sum_{i\in S}(c_i-v_i)-h\) | Net **qualified verification work saved** on receiver obligations, assuming commensurate unit and valid reuse. |
| \(\frac{n_p}{n}(\mu_p-\mu_c)\) | Source-derived **bias from mixing distinct regime means** in a declared mean-estimation model. |
| \(V(C)\) or \(R^*(O)\) | Decision **loss criterion**, relative to actual actions, target, model, prior or robust set; not the same as Shannon bit count. |

A symbol \(\Omega\) used for R12's verification-work units is **not** the same object as Part I's open universe \(\Omega\). Likewise neither \(\mathrm{UNKNOWN}\) nor \(\mathrm{A′}\) is automatically a random variable with an inferable probability distribution.

## 3. Priority and scientific boundary

**Established mathematics reused:** Kleene/Post c.e. witness relation, Shannon conditional entropy inequality and log-loss identity, reverse-KL conditioning identity, Kolmogorov description bounds, orbit invariance, finite congruence/pair cover, compiler equivalence, elementary proof-reuse accounting, bias–variance decomposition. None is claimed as an original universal theorem of this programme.

**Author's historical research programme:** border/ND, composition and primitive syntactic differences, source/recipient projection, formal meta-positioning, computational exergy, incomplete evidence/entropic distortion, context-dependent semantic windows. The historic originals express some significantly stronger metaphysical/physical/probability claims which were corrected, qualified or left open by later reviews. **Do not silently promote those claims**.

**Present derived contribution:** a **coherent metasyntactic utility problem class** connecting exact task relevance, qualified proof and source scope, anonymous relation, contextual interpretation and separate information-vs-verification-work measures; the integration is a mathematical *research construction*, not independent peer validation or a protected runtime standard.

**Forbidden extrapolations at this phase:** assuming every real open ecosystem has accessible outside agents or an available qualified signal; asserting universal Bayesian priors over the uncomputable residual; treating all missing facts as retrievable or all contradictions as physically dangerous; claiming a measure of Shannon uncertainty is a count of physical robots; treating raw data compression as substantive task sufficiency; proving actual net savings or safe deployment from a conditional algebraic inequality; importing a mandatory ABCD role partition, social-game model or adopted Ecosystem Awareness functional requirement into mathematical Part II.
