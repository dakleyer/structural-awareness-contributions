## Reproduction

Use Python 3.10 or later, standard library only:

```sh
python3 run_audit.py
python3 replay_and_review.py
```

The first command writes results.json; the second writes review_results.json. Both use assertions and return nonzero on a failed declared acceptance check. Adverse mutant and hidden-change results are expected scientific outputs and are retained as such. Counts are overlapping model assignments or event words, not independent real-world incidents. PROTOCOL.sha256 records the local design freeze. SOURCE_MANIFEST.json pins source bytes. This is not external preregistration or independent peer review.
