## 2. The causal claim, with its quantifiers preserved

The controlling formulation in Protocol 0.3 is:

> **HC — Common causal sufficiency through contextual change and unqualified reuse.** For each of the six failure modes 00E–00J, there exists an admissible configuration in which information is transmitted or retained without sufficient decision-relevant contextual qualification, the applicable context changes materially, and that information is subsequently reused without adequate reassessment, producing the independently defined failure mode under specified background conditions.

The proposed common cause is that **configured causal sequence**, including its background conditions. Context change by itself is not claimed to cause every failure. HC does not claim that every instance needs context change or that the same parameter values reproduce all six families. Static failure routes remain valid controls and alternative causal explanations.

For a causal witness, the intervention must participate in producing the independently scored outcome. Temporal order or a change in the agent's belief is insufficient. The protocol specifies matched controls and targeted interventions in context and qualification handling. One failed candidate limits that candidate; refuting the bounded all-six claim requires the declared configuration-domain obligation specified in the protocol.

**HS is a separate claim:** a communication, contrast and response mechanism may be sufficient within a declared scope and budget. A correct signal alone does not establish prevention, legitimate continuity or superiority. The empirical H1–H6 remain separate research questions; HC is not a replacement H7.

These are formulated causal and response hypotheses, not an already established universal root-cause conclusion. The exact definitions, six family-specific proposals and refutation conditions remain in Protocol 0.3.
