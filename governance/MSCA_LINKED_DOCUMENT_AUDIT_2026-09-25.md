# Auditoría de conservación — README de Minimum Sufficient Control / MSCA

**Fecha:** 25 de septiembre de 2026. **Objeto:** el README vigente de `standards/minimum-sufficient-control/` y sus **18 archivos locales distintos** enlazados directamente. Sus historiales por ruta sumaban **292 revisiones antes de esta restauración**; la corrección del README DAOS suma una revisión adicional al publicarse. Esta auditoría distingue pérdida del texto vigente, traslado a otra fuente, corrección de sentido y mero cambio de enlace.

## README y reconstrucción

El README inicial de 29 de agosto ([commit `36dbf7e`](https://github.com/dakleyer/structural-awareness-contributions/blob/36dbf7e/standards/minimum-sufficient-control/README.md)) perdió su explicación extensa al convertirse en un índice el 15 de septiembre (`f0ce88b`). Su texto exacto permanece **byte por byte** en [ARCHITECTURE_AND_STANDARDS_CONTEXT.md](../standards/minimum-sufficient-control/ARCHITECTURE_AND_STANDARDS_CONTEXT.md), incluido el diagrama de posición en el programa, las cinco dimensiones candidatas y las seis preguntas de investigación. El README actual enlaza esa fuente y conserva el límite de no adopción ni validación. Se añadió una sola frase para dejar clara la identidad exacta de la fuente histórica.

Las revisiones del 23 de septiembre convirtieron el índice en una ruta canónica S/E/C/P/M: Architecture, Composition/Cartography, Architectural Role, Operation/Repositioning y perfil ACC; mantuvieron por separado 01B y 01D como interfaces candidatas, el input presentado como procedencia y el artículo II como antecedente. La retirada de la etiqueta **PENDING** para Operation coincidió con la creación del documento enlazado; no se debe restaurar ese estado antiguo como vigente. La antigua 01B v0.1 queda accesible desde la [v0.2](../research/ecosystem-awareness/baseline/01B_EA_MSCA_INTERFACE_ANNEX_v0.2.md), que la cita expresamente.

**Verificación de rutas:** 18/18 archivos locales del README existen; no hay destinos locales inexistentes en sus enlaces de segundo nivel. Se contaron 496 referencias Markdown en esos 18 archivos; esta comprobación de ruta no equivale a revisar la veracidad de cada afirmación ni a probar todos los fragmentos remotos. Los cinco enlaces externos del README apuntan a Tegrity.AI: el buscador indexa el artículo MSCA y Cost of Clarity; el acceso directo al sitio agotó el tiempo para las cinco URLs, de modo que su respuesta HTTP actual queda **sin certificar**.

## Resultado y límite

El README actual es un índice acumulativo de la arquitectura MSCA vigente, mientras que el texto inicial está preservado exactamente como contexto. La pérdida concreta adicional estaba en el README DAOS enlazado: procedencia y valores de custodia históricos; ambos se restituyeron con etiqueta temporal. Los cambios de Cartography, ACC y Repositioning son revisiones arquitectónicas expresas y no deben revertirse a fórmulas o permisos anteriores sin una nueva decisión de diseño.

Se verificaron rutas y pasajes de mayor riesgo de los 18 historiales; esto no demuestra equivalencia palabra por palabra de las **292 revisiones anteriores** ni ejecución/validación empírica de MSCA. Los registros de procedencia Word solo prueban qué hashes constaban en el README antiguo, no que hoy estén disponibles o sean correctos frente a los archivos fuente.

**Segunda pasada (25 de septiembre):** el contraste de retiradas extensas y encabezados renumerados no identificó otra sección completa extraviada en los documentos MSCA. La nota de compatibilidad de Cartography ya nombra correctamente `ECM_i` como notación anterior. Sí permanecía una referencia interna desfasada en el perfil ACC: citaba `RESTORE` como resultado vigente de Operation tras su sustitución por `REALIGN_TARGET` y solicitudes de control. Se corrigió esa línea sin reintroducir facultades de ejecución anteriores.
