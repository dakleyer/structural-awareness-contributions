# Auditoría de conservación — Regime Awareness / Regime Change Detection

**Fecha:** 25 de septiembre de 2026. **Alcance:** [README de Regime Awareness](../research/regime-awareness/README.md), sus **16 destinos locales Markdown distintos** y sus cuatro enlaces externos directos. Los historiales de esos 16 archivos suman **327 revisiones por ruta** al corte de esta auditoría; varios archivos pertenecen también a los corpus EA y MSCA ya auditados. Se revisaron cambios retirados, versiones preservadas, responsabilidades semánticas y rutas. Una ruta existente o un historial numeroso no prueba por sí solo que todas las afirmaciones científicas sean correctas.

## Doble comprobación previa de MSCA

El [primer README de MSCA (`36dbf7e`)](https://github.com/dakleyer/structural-awareness-contributions/blob/36dbf7e/standards/minimum-sufficient-control/README.md) y el actual [contexto de arquitectura](../standards/minimum-sufficient-control/ARCHITECTURE_AND_STANDARDS_CONTEXT.md) son **el mismo blob Git** (`d9b2d4baf3c76e93f69727277e3302f5eff0c3c7`). La pérdida aparente de 52 líneas al convertir el README en índice (`f0ce88b`) fue un traslado íntegro, y la versión vigente enlaza esa fuente histórica. La [arquitectura canónica MSCA](../standards/minimum-sufficient-control/00_CANONICAL_MSCA_ARCHITECTURE.md) nació con 455 líneas (`25db478`) y tiene 557: sus 13 revisiones por ruta incorporaron cualificación de posición, Objective Envelope, ACC, composición y operador de postura; las retiradas de mayor tamaño sustituyeron estados **PENDING** y atribuciones de responsabilidad por documentos ya existentes. No se identificó una sección canónica perdida sin sustitución. La [auditoría de MSCA](./MSCA_LINKED_DOCUMENT_AUDIT_2026-09-25.md) registra el resto de sus destinos y la restitución histórica DAOS.

## README de Regime Awareness

El README inicial (`4f59134`, 29 de agosto) tenía 154 líneas de explicación del programa, diagrama, seis preguntas, límites de evidencia y ruta QAVA. Su blob `c9b2a614423238842010537679e2ba77cb895b02` coincide **exactamente** con el actual [PROGRAMME_CONTEXT.md](../research/regime-awareness/PROGRAMME_CONTEXT.md), creado en `f0ce88b`; el README actual lo enlaza expresamente y se añadió una frase para identificar esa conservación exacta. La transformación en índice retiró 147 líneas del README visible, **sin perder el texto del repositorio**. Las 15 revisiones posteriores del README añadieron la ruta de cuatro series, el circuito de entradas/salidas, la tabla productor/consumidor y la distinción entre el detector direccional `P_t`, el delta `Δ_RA` y la postura operativa P1/P2/P3. La antigua posibilidad de una postura candidata emitida por RA fue reemplazada por la responsabilidad canónica de MSCA Operation; reintroducirla como responsabilidad actual sería incoherente con el contrato vigente.

**Comprobación de rutas:** 16/16 destinos locales directos existen. En esos 16 archivos se contaron 565 referencias Markdown (incluidas 95 externas) y **ninguna ruta local de segundo nivel inexistente**. Se comprobó existencia de archivo/directorio, no la veracidad de cada fuente externa ni cada fragmento de ancla. Los cuatro enlaces externos directos del README (series RA, Cost of Clarity, Human Intelligence Gap e Informational Friction) devolvieron páginas indexadas al consultarlos. En el [índice EWS](../research/regime-awareness/minimalistic-early-warning-systems/README.md), tres de sus cuatro artículos Tegrity se pudieron consultar; la URL específica del artículo ancla `minimalistic-regime-aware-early-warning-systems/` agotó el tiempo de acceso directo y su estado HTTP actual queda **sin certificar**, aunque el documento padre `1379-2/` sí responde. No se sustituyó una URL histórica sin verificar su destino.

## Conclusión y límite

No se detectó otra pérdida sustantiva que requiera editar los 16 documentos en esta revisión. El README de RA perdió longitud visible al convertirse en índice, pero el texto original está preservado exactamente y enlazado; el corpus distingue la prueba mínima de cambio observable de la integración arquitectónica más amplia. Este contraste de historiales, rutas y pasajes de mayor riesgo **no equivale a una prueba de igualdad semántica de todas las 327 revisiones** ni a validación empírica del detector o de la arquitectura RA.
